HW 01: Simple linear regression

Tennis

ImportantDue date

This assignment is due on Thursday, September 10 at 11:59pm. To be considered on time, the following must be done by the due date:

  • Final .qmd and .pdf files pushed to your GitHub repo
  • Final .pdf file submitted on Gradescope

Introduction

In this assignment, you will use simple linear regression to explore the variability in win percentage based on the percentage of return points for professional tennis players. You will also explore the mathematical properties of linear regression models.

Learning goals

In this assignment, you will…

  • use matrix operations to show results about simple linear regression.
  • conduct exploratory data analysis.
  • fit and interpret simple linear regression models.
  • evaluate model fit.
  • continue developing a workflow for reproducible data analysis.

Getting started

  • Go to the sta221-fa26 organization on GitHub. Click on the repo with the prefix hw-01. It contains the starter documents you need to complete the assignment.

  • Clone the repo and start a new project in RStudio. See the Lab 00 instructions for details on cloning a repo and starting a new project in R.

Conceptual exercises

ImportantInstructions

The conceptual exercises are focused on explaining concepts and showing results mathematically. Show your work for each question.

You may write the answers and associated work for conceptual exercises by hand or type them in your Quarto document.

Exercise 1

In lecture, we introduced \(\mathbf{H}\), the hat matrix, as a projection matrix that projects \(\mathbf{y}\) onto \(\text{Col}(\mathbf{X})\) in linear regression. Here we will show some properties of \(\mathbf{H}\).

  1. Show that \(\mathbf{H}\) is symmetric \((\mathbf{H}^\mathsf{T} = \mathbf{H})\).
  2. Show that \(\mathbf{H}\) is idempotent \((\mathbf{H}^2 = \mathbf{H})\).
  3. Show that \(\text{rank}(\mathbf{H}) = 2\) in simple linear regression.

Exercise 2

Show that the Hessian matrix \(\frac{\partial^2}{\partial \boldsymbol{\beta}^2}\boldsymbol{\epsilon}^\mathsf{T}\boldsymbol{\epsilon} = 2\mathbf{X}^\mathsf{T}\mathbf{X}\) is positive definite. Assume \(\mathbf{X}\) has full column rank.

Exercise 3

Show that the least-square estimator \(\hat{\boldsymbol{\beta}}\) can be written as

\[\hat{\boldsymbol{\beta}} = \boldsymbol{\beta} + (\mathbf{X}^\mathsf{T}\mathbf{X})^{-1}\mathbf{X}^\mathsf{T}\boldsymbol{\epsilon}\]

Assume \(\mathbf{X}\) has full column rank.

Exercise 4

Instead of finding the estimator that minimizes the sum of squared error, we wish to find the estimator that minimizes the following:

\[(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^\mathsf{T}(\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) + \lambda\boldsymbol{\beta}^\mathsf{T}\boldsymbol{\beta}\]

such that \(\lambda > 0\) is a scalar and \(\mathbf{X}\) has full column rank.

Find \(\hat{\boldsymbol{\beta}}\) that minimizes this objective function. Show your derivation and confirm that your solution minimizes the objective function.

Exercise 5

Show that the sum of squared residuals (SSR) can be written as the following:

\[\mathbf{y}^\mathsf{T}\mathbf{y} - \hat{\boldsymbol{\beta}}^\mathsf{T}\mathbf{X}^\mathsf{T}\mathbf{y}\]

Applied exercises

ImportantInstructions

The applied exercises are focused on using the methods from the course to analyze data and answer questions about real-world phenomena.

All work for the applied exercises must be typed in your Quarto document. Remember to render, commit, and push your work to GitHub regularly.

Write all narrative using complete sentences and include informative axis labels / titles on visualizations.

Data: Tennis 🎾

The data for this analysis includes the percentage of return points and the win percentage for matches played by 148 players in the Association of Tennis Professionals (ATP). The percentages are computed based on the performance over the 52 weeks prior to May 27, 2024. The data only includes the players’ performance on hard court surfaces during this time period, and it is filtered to only include players who played at least 10 matches overall or at least five matches on hard court surfaces.

The data are originally from Wheelo Ratings, a website containing performance statistics for ATP players. The data set was obtained from the SCORE Sports Data Repository.

tennis <- read_csv("data/tennis-hardcourt.csv")

The analysis will focus on the following variables:

  • return_pct: Percentage of return points won, i.e., percentage of points won on competitor’s serve

  • win_pct: Percentage of matches won

Analysis goal

The goal of the analysis is to use the percentage of return points won to explain variability in the percentage of matches won for the ATP players.

Exercise 6

Let’s start by exploring the response and predictor variables.

  1. Visualize distribution of the response variable win_pct. Describe the distribution.

  2. Visualize the relationship between return_pct and win_pct. Based on the visualization, would a linear regression model reasonably summarize the relationship between the two variables? Briefly explain.

Tip

The description should include shape, center, spread, and presence of outliers. Use specific values in your description. See Section 3.4.2 of Introduction to Regression Analysis for more information about describing univariate distributions. See the ggplot2 reference for example code and plots.

Exercise 7

We will fit a model using return_pct to explain variability in win_pct. The model takes the form

\[\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\epsilon}\]

  1. State the dimensions of \(\mathbf{y}\), \(\mathbf{X}\), \(\boldsymbol{\beta}\), \(\boldsymbol{\epsilon}\) for this analysis. Your answer should have exact values given this data set.
  2. Estimate the regression coefficients \(\hat{\boldsymbol{\beta}}\) in R using the matrix representation. Show the code used to get the answer.
  3. Check your results from part (b) by using the lm function to fit the model. Neatly display your results using 3 decimal places.
TipMatrix operations in R

You can use the model.matrix() function to get the design matrix. The code takes the general form:

model.matrix(y ~ x, data = my_data)

Matrix operations:

  • Addition/Subtraction: A + B and A - B

  • Multiplication : A %*% B

  • Transpose of A: t(A).

Exercise 8

  1. Compute \(SST\), \(SSM\) and \(SSR\) for the model from the previous exercise. Show the code used to compute these values from the appropriate sums (not just built-in R functions). Use the values to show the equality \(SST = SSM + SSR\) holds.

  2. Use the results from part (a) to compute \(R^2\) and interpret it in the context of the data.

  3. Use the data to show that for simple linear regression, \(R^2\) is equal to \(cor(x, y)^2\) and \(cor(y, \hat{y})^2\). Note: \(cor(a,b)\) is the correlation between \(a\) and \(b\).

Exercise 9

  1. Interpret the slope for the model fit in Exercise 7 in the context of the data.

  2. The intercept is negative, which is not possible in practice. Explain why the model might produce such an intercept in this analysis.

Exercise 10

  1. U.S. player Ben Shelton had a return percentage of 34.470 during this period. Based on the model, what is the predicted win percentage for this player?

  2. During this period, he won 63.415% of matches. What is the residual for this player?
